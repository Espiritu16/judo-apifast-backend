# JUDO Backend API

Este repositorio mantiene el codigo fuente del backend en la rama `dev`.

## Ramas

| Rama | Uso |
|---|---|
| `main` | Rama principal informativa. No contiene el codigo de desarrollo. |
| `dev` | Rama de desarrollo con el backend FastAPI completo. |

## Como trabajar

```bash
git fetch origin
git switch dev
```

Los cambios del backend deben realizarse y subirse desde `dev`.
